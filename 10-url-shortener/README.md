# URL Shortener (Logic Only)

**Type:** CLI, Logic-based application

## Description

A simple URL shortener that converts long URLs into short codes using in-memory mapping logic.

## Features

- Generate unique short URLs
- Prevent duplicate URL entries
- Expand short URL to original URL
- View all stored URL mappings

## Concepts Used

- Dictionaries
- Random string generation
- Mapping logic
- Input validation
- Loop-based menu

## How to Run

```bash
python main.py
```
