# Mini Search Engine (CLI)

Type: CLI Application

## Description

A simple command-line search engine that searches through predefined documents and ranks results based on relevance.

## Features

- Keyword-based search
- Case-insensitive matching
- Relevance ranking
- Clean CLI output

## Concepts Used

- Dictionaries
- String normalization
- Search algorithms (basic)
- Sorting with key functions
- Modular code (main.py + utils.py)

## How to Run

```bash
python main.py
```
