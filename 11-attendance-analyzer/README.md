# Attendance Analyzer (CLI)

**Type:** CLI, logic-based application

## Description

Python CLI application to analyze student attendance and determine eligibility based on attendance percentage.

## Features

- Add student attendance
- Calculate attendance percentage
- Determine eligibility (≥ 75%)
- View attendance report

## Concepts Used

- Functions
- Lists & dictionaries
- Conditional logic
- Input validation
- Basic calculations

## How to Run

```bash
python main.py
```
